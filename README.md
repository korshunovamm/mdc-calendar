# Танцы NRG Пролетарская → календарь iCloud

`build_ics.py` каждый день в 9:00 (МСК) собирает `docs/dance.ics` с выбранными занятиями на 30 дней вперёд.
Отменённые и перенесённые занятия не попадают в файл, замены преподавателей помечаются «(замена)».

## Установка (один раз)

1. На github.com создайте **публичный** репозиторий, например `dance-calendar`.
2. Загрузите в него содержимое этой папки (включая скрытую `.github`).
3. Settings → Pages → Source: `Deploy from a branch`, ветка `main`, папка `/docs`.
4. Actions → «Обновить расписание» → Run workflow (первый запуск вручную).
5. Ссылка на календарь: `https://<ваш-логин>.github.io/dance-calendar/dance.ics`
6. На iPhone: Настройки → Календарь → Учётные записи → Новая → Другое → Добавить календарь-подписку, вставить ссылку.
   На Mac: Календарь → Файл → Новая подписка на календарь.
   В свойствах подписки выберите цвет «Отдых» и интервал обновления «Каждый час».

## Что менять

В `build_ics.py`: список `INCLUDE` — какие направления нужны, `EXCLUDE` — что скрыть,
`BRANCH_ID` — филиал (1 = Пролетарская).
